# 三年級數學樂園（五福國小・南一版 三上）

高雄市鳳山區五福國民小學，115 學年度上學期，三年級數學。
版本：**南一**（學校官方教科書單）。這一版取代舊的康軒版三上遊戲（`publish/math5a-lab/grade3/`），單元依南一課本重新製作，題目全部重寫。

## 怎麼玩
- 直接用瀏覽器打開 `index.html` 就能玩，不用網路、不用安裝；滑鼠和平板觸控都可以操作。
- 題目由「貓頭鷹老師」朗讀（Web Speech API，zh-TW），右上角可關聲音，🔊 可以再唸一次。
- 多位數答案用數字小鍵盤輸入；直式題一格一格按 0～9。
- 每關最多 3 顆星：全對 3 顆、錯 1–2 次 2 顆、錯更多 1 顆。存在 localStorage（key：`math-g3-stars`），首頁可以清除。
- 左上角「← 選年級」連到 `../index.html`。全站「回遊戲樂園」按鈕（`home-button.js`）由總管統一加入。
- 全部使用相對路徑、沒有外部圖片，整個資料夾可直接複製到 repo 的 `grade3/`。

課本單元末的「加油小站」、「魔數小偵探」等複習活動沒有另外做關卡，各單元挑戰關已涵蓋。題目數字每次隨機產生。
範圍刻意控制在三上：加減在 10000 以內；乘法只到三位數 × 一位數；除法只有二位數 ÷ 一位數、商是一位數（「餘數的應用」「至少幾輛」等在三下）；分數只做真分數與 d/d＝1，不做分數加減式（三下「分數的加減」）。
