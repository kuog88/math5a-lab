# 六年級數學樂園（五福國小・南一版 六上）

高雄市鳳山區五福國民小學，115 學年度上學期，六年級數學。版本：**南一**（學校官方教科書單）。

## 怎麼玩
- 直接用瀏覽器打開 `index.html` 就能玩，不用網路、不用安裝；滑鼠、平板觸控都可以操作。
- 題目由「貓頭鷹老師」朗讀（Web Speech API，zh-TW），🔊 可再聽一次，右上角可關聲音。
- 答案用小鍵盤輸入：可輸入小數（.）、分數（／）、帶分數（又）、比（:）；分數和比要化到最簡。
- 每關最多 3 顆星（全對 3、錯 1–2 次 2、更多 1），存在 localStorage key `math-g6-stars`。
- 左上「← 選年級」連到 `../index.html`；全站 `home-button.js` 由總管統一加入。全部相對路徑，可直接複製到 repo 的 `grade6/`。
