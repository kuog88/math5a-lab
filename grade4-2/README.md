# 四年級下學期・恐龍谷化石探險隊（數學）

- 115 學年度四下數學，**一開始就支援南一、康軒、翰林三個版本**（預設南一）。
- 主題：恐龍谷化石探險隊。配色是火山橘、叢林綠、化石米白、深橄欖，教練是「小暴龍隊長」🦖，獎勵是化石 🦴。和四上的粉色「數學樂園」明顯不同。
- 入口 `index.html`；左上「← 選年級」連到 `../index.html`。進度存在 localStorage `math-g4-2-stars`，key 是「內部單元代號-關卡」（例如 `big-0`），換版本不會遺失。
- 每個內部單元有 4 關：🖐 動手做、💡 想一想、🏆 挑戰、🎯 進階挑戰（5 題考卷陷阱題，每題有詳解和「⚠️ 小心陷阱」）。每關最多 3 塊化石。

### 補做的單元與依據
四下是整冊新做，所以三個版本的每個單元都是新的關卡。其中只出現在部分版本的主題：
- **數量規律**（康軒 4、翰林 10）：依 108 課綱 R-4-4「數量模式與推理」，做了圖形規律（火柴棒正方形、三角形、正方形點陣）、數列規律、奇偶數與排列規律。
- **四則運算與簡化計算**（康軒 8、翰林 2）：依 R-4-1「兩步驟問題與併式」、R-4-2「四則運算的性質」，做了「先算哪一個」（括號 → 先乘除後加減 → 由左到右）、加法交換律／結合律、連減、連乘、連除的性質、湊整與併式列式。**不教分配律**（南一放到五上，課綱四年級也沒有）。
- **長條圖與折線圖**（南一 5）：依 D-4-1「報讀長條圖與折線圖、製作長條圖」，做了畫長條圖、讀長條圖、折線圖的變化、複雜長條圖、縱軸有省略符號的陷阱。
- **同分母分數的加減與整數倍**（南一 3、翰林 4）：依 N-4-5，含帶分數加減（借 1）、假分數與帶分數互換、分數的整數倍。分母大多用質數，避免四年級還沒學的約分。
- **等值分數**：依 N-4-6、N-4-8，含「簡單異分母」（一個分母是另一個的倍數）的比較與加減（康軒、翰林課程計畫有寫加減；南一 8-3 只寫比較），以及分母 10、100 的分數和小數互換。

依據的資料：
- 單元目錄：`curriculum/math.json`（四下三版本，來源是彰化縣 115 學年度各校課程計畫：南一 plans/1489、1601、1606、1640；康軒 plans/1368、1443、1465、1578；翰林 plans/1362、1379、1410、1546，網址 `https://curriculum.chc.edu.tw/years/115/plans/<id>/views/5-4數學.pdf`），對照均一教育平台 `https://www.junyiacademy.org/course-compare/{n,k,h}-m4a`。
- 學習內容：十二年國教數學領綱學習內容 N-4-2、N-4-4～N-4-8、N-4-11～N-4-13、S-4-3～S-4-5、S-4-8、R-4-1～R-4-4、D-4-1（國家教育研究院課綱說明）。
- 範圍提醒（不超綱）：乘數、除數至多三位數；小數只到小數 × 整數；體積只數積木（一層幾個 × 幾層），不教長方體公式；分數不做約分、不做一般異分母加減。

### 從其他年級搬來的關卡
沒有直接搬關卡。畫圖工具（等角積木 `isoSVG`、百格圖 `grid100SVG`）和列式小幫手、分數鍵盤由五下 `grade5-2` 沿用，改成四下的配色；進階挑戰 `adv()` 參考二下的寫法。

## 列式小幫手
應用題、求□題都用 `eqBuild`（列對算式就由電腦算答案），例如：
- 多位數：化石運送應用題（乘、除、兩步找錢）、進階的「被除數 ＝ 除數 × 商 ＋ 餘數」。
- 四邊形：菱形邊長、平行四邊形周長、由周長求另一邊。
- 分數：分數的整數倍、剪掉、合起來、「1 − 兩次用掉」。
- 統計圖：相差、合計（數字按鈕直接給圖上的數）。
- 小數乘法：每瓶×瓶數、兩步加減。
- 周長與面積：長方形面積／周長、L 形面積（三種切法都算對）、由面積求長、由周長求寬。
- 體積：一層 × 層數、由體積求層數或寬。
- 數量規律：第 n 個圖形的火柴棒數、方桌坐人、第 n 個奇數。
- 四則：併式找錢、先乘再平分。
沒有改用列式的：直式計算練習、取概數、時間換算、讀圖選擇、觀念題（那些是在練計算或觀念本身）。

## 家長報表
沿用五下的接法：`api.ok/bad` → `rep()`，`quiz`／`adv`／`eqBuild` 會設定 `curQ`（題目與正確答案）；動手做關卡的錯誤也傳孩子的操作和正確答案（例如「你圍出來的是梯形」→「正方形」）。`openLevel` 呼叫 `KGReport.level('單元號-A～D 關卡名', '第 N 單元 版本單元名（版本）')`，過關呼叫 `KGReport.done({ stars })`。

## 📝 月考測驗卷
- 三份試卷：期中考範圍（前 5 單元，45 題）、期末考範圍（後 5 單元，45 題）、全冊總複習（50 題），範圍依目前版本自動組成。
- 每個主題 37～44 題（亂數函式算 5 題），是非、選擇、填充都有；陷阱題約 34%～69%。
- 題型、陷阱參考公開的四年級段考與評量常見錯誤（餘數補 0、分母相加、四捨五入的範圍、縱軸省略符號、借 1 時 ＝ 60 分、拿走一整層、連減去括號），題目文字和數字都是自己重寫的。

## 測試
- `node --check` 全部 js。
- node 驗算腳本：每個 quiz／進階題的產生器跑 300 次，檢查列式小幫手的正確算式、其他列法的值都等於答案、選擇題只有一個正確選項、沒有 NaN、答案不是負數。
- node 題庫檢查：三版本單元數、順序、名稱和 `curriculum/math.json` 一致；每個 bankUnits 至少 25 題；用 `KGVer.examBank` 組三個版本的三份試卷，每份都抽到 45～50 題、每個單元都抽得到。
- 瀏覽器（先關背景音樂與音效）：三個版本切換、全部 48 關自動玩完並記錄化石、三版本期中試卷各寫一次、手機 375 寬。
