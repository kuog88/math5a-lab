# 六年級下學期・星際太空站任務隊（數學）

- 115 學年度六下數學，**一開始就支援南一、康軒、翰林三個版本**（預設南一）。
- 主題：星際太空站任務隊。深夜藍背景＋霓虹青、電光紫、星光黃，教練是「機器人艦長」🤖，獎勵是能量晶石 💠。和六上的粉色「數學樂園」明顯不同。
- 入口 `index.html`；左上「← 選年級」連到 `../index.html`。進度存在 localStorage `math-g6-2-stars`，key 是「內部單元代號-關卡」（例如 `mixed-0`），換版本不會遺失。
- 每個內部單元 4 關：🖐 動手做、💡 想一想、🏆 挑戰、🎯 進階挑戰（5 題考卷陷阱題，每題有詳解和「⚠️ 小心陷阱」）。每關最多 3 顆晶石。

### 補做的單元與依據
六下是整冊新做，三個版本的每個單元都是新的關卡。只出現在部分版本的主題：
- **放大圖、縮圖與比例尺**（南一 4）：依 S-6-1，做了方格上畫 2 倍、3 倍放大圖和 1/2 縮圖、對應邊與對應角、比例尺（1：□、線段比例尺、圖上 ↔ 實際距離換算）。
- **基準量與比較量**（南一 3、康軒 4）：依 N-6-8，做了線段圖、判斷基準量、比較量 ＝ 基準量 × 比值、基準量 ＝ 比較量 ÷ 比值、兩量和、兩量差、打折與增加百分率。
- **速率**（康軒 2 的平均速率、翰林 3）：依 N-6-7，做了比快慢（含不同單位）、距離／時間／速率、時速分速秒速換算、平均速率（總距離 ÷ 總時間）、火車過橋。
- **相遇、追趕與流水**（南一 5、康軒 2、翰林 5）：依 N-6-9、R-6-2、R-6-3，做了飛船相遇模擬、相遇與相離、追趕、先出發的追趕、環形跑道、順水逆水。
- **圓面積與扇形面積**（翰林 2）：依 S-6-3，做了圓切成小片拼成近似長方形、圓面積、由直徑求面積、扇形（只出面積是有限小數的半徑與圓心角）、圓環、正方形減圓等複合圖形。
- **怎樣解題**：南一（年齡、雞兔、追趕、流水）、康軒（和差、年齡、雞兔、組合、堆疊）、翰林（追趕、年齡、平均）都收在 `solve`＋`chase` 裡；組合用「搭配」「握手」「選 2 人」，堆疊用「三角形疊罐」。

依據的資料：
- 單元目錄：`curriculum/math.json`（六下三版本，來源是彰化縣 115 學年度各校課程計畫：南一 plans/1465、1515、1579、1606；康軒 plans/1362、1368、1379、1443；翰林 plans/1410、1454、1511、1546，網址 `https://curriculum.chc.edu.tw/years/115/plans/<id>/views/5-6數學.pdf`），對照均一教育平台 `https://www.junyiacademy.org/course-compare/{n,k,h}-m6a`。
- 學習內容：十二年國教數學領綱 N-6-5、N-6-7、N-6-8、N-6-9、R-6-1～R-6-4、S-6-1、S-6-3、S-6-4、D-6-1、D-6-2（國家教育研究院課綱說明）。
- 範圍提醒（不超綱）：圓周率一律 3.14；可能性只比較大小（「一定、可能、不可能」），不用機率數值；放大縮圖只談邊長倍數和角度不變，不出面積倍數；平均速率用總距離 ÷ 總時間。

### 從其他年級搬來的關卡
沒有直接搬關卡。列式小幫手、分數鍵盤、進階挑戰由四下 `grade4-2`（源自五下）沿用並換成六下的配色與提示用語。

## 列式小幫手
應用題、求□題用 `eqBuild`（列對算式就由電腦用精確分數算答案，支援分數、小數、百分率、括號、多步），例如：燃料剩餘、平分、剪段、太陽能板面積；圓形圖人數、百分率反求全部；比較量、基準量、兩量和差、打折、增加百分率；比例尺線段圖；和差、年齡、雞兔、平均、搭配；相遇、相離、追趕、順逆水；速率三公式、平均速率、火車過橋；柱體體積、表面積、挖洞；圓面積、扇形、圓環、複合圖形。
沒有改用列式的：依順序計算（動手做）、單位換算、比例尺換算填數、讀圖選擇、觀念題、握手與疊罐（是在練找規律）。

## 家長報表
沿用四下的接法：`api.ok/bad` → `rep()`；`quiz`／`adv`／`eqBuild` 設定 `curQ`；動手做關卡答錯也傳孩子的操作和正確答案（例如「底 4、高 3」→「底 6、高 4」）。`openLevel` 呼叫 `KGReport.level('單元號-A～D 關卡名', '第 N 單元 版本單元名（版本）')`，過關呼叫 `KGReport.done({ stars })`。

## 📝 月考測驗卷
- 三份試卷：期中考範圍（前 3 單元，45 題）、期末考範圍（後 3 單元，45 題）、全冊總複習（50 題），範圍依目前版本自動組成。
- 每個主題 38～39 題（亂數函式算 5 題），是非、選擇、填充都有；陷阱題約 36%～68%。
- 題型、陷阱參考公開的六年級段考與評量常見錯誤（直徑當半徑、扇形用 /100、平均速率不是速率平均、打折反求原價、基準量換了百分率不同、角度放大不變、相遇用和追趕用差、黏起來少兩個面），題目文字和數字都是自己重寫的。

## 測試
- `node --check` 全部 js。
- node 驗算腳本：每個 quiz／進階題的產生器跑 300 次，檢查列式小幫手的正確算式、其他列法的值都等於答案、選擇題只有一個正確選項、沒有 NaN、答案不是負數。修正：扇形面積原本會出 104.666… 這種除不盡的答案，改成只用面積是有限小數的半徑與圓心角組合；用到 3.14 的題目都標「（圓周率 3.14）」。
- node 題庫檢查：三版本單元數、順序、名稱和 `curriculum/math.json` 一致；每個 bankUnits 至少 25 題；三個版本的三份試卷都抽到 45～50 題、每個單元都抽得到。
- 瀏覽器（先關背景音樂與音效）：三個版本切換、全部 36 關自動玩完並記錄晶石、三版本期中試卷各寫一次、手機 375 寬。
