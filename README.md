👉 **線上遊玩：https://kuog88.github.io/math5a-lab/**（先選年級）

## 🌈 三年級數學樂園（`grade3/`）

卡通可愛風格，每單元 3 關（動手玩 🎮、想規則 🧩、挑戰題 🎯），老師說的話可以按 🔈 朗讀。

| 三上單元 | 關卡 |
|---|---|
| 1 10000 以內的數 | 積木倉庫・收銀台湊錢・比大小 |
| 2 四位數的加減 | 進位火箭・借位換錢機・直式步驟 |
| 3 毫米 | 放大鏡量尺・長度接龍・公分毫米換算 |
| 4 乘法 | 蛋盒切切看・乘法進位工廠・連乘兩步驟 |
| 5 角 | 鱷魚張嘴比大小・直角卡偵探・角的觀念 |
| 6 面積 | 方塊鋪地板・剪刀拼拼看・平方公分 |
| 7 除法 | 分糖果機・試商猜猜看・餘數的秘密 |
| 8 公升和毫升 | 量杯倒水・果汁調配站・容量換算 |
| 9 分數 | 平分蛋糕・分數跳格子・幾分之幾 |

三下 9 個單元（分數的加減、除法、尋找規律、公斤和公克、小數、圓、乘法與除法、時間、統計表）製作中。
