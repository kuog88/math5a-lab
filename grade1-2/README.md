# 一年級下學期・森林小火車（數學）

- 學校：高雄市鳳山區五福國民小學，115 學年度**下學期**（一下）
- 版本：**南一版** 一下數學（9 個單元，單元目錄與來源見 `UNITS.md`）
- 入口：`index.html`（可直接用瀏覽器開啟，離線可玩；滑鼠、觸控都可以操作）
- 進度存在 localStorage，key：`math-g1-2-stars`（不會和上學期 `math-g1-stars` 混在一起）
- 左上角「← 選年級」連到 `../index.html`；`home-button.js`、`bgm.js` 由總管統一加入
- 每個關卡畫面的標題元素是 `#lvTitle`（class `lv-title`），首頁標題是 `h1.hub-title`

## 主題與風格（和上學期明顯不同）
| | 上學期（grade1） | 下學期（grade1-2） |
|---|---|---|

## 一年級的設計
- 字大（題目 27px 以上、數字 46px），按鈕大、好點。
- 每題自動朗讀，泡泡右上角 🔈 可以再唸一次（Web Speech API，zh-TW）；右上角 🔊 可以關掉聲音。
- 算式只用 ＋、−、＝（一上已學過），要填的答案用「？」框表示，不出現 ＞、＜、×、÷ 等還沒教的符號。
- 數的範圍：第 1 單元到 100；第 2、4 單元 18 以內；第 8 單元 60 以內。
