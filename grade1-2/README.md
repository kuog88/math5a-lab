# 一年級下學期・森林小火車（數學）

- 學校：高雄市鳳山區五福國民小學，115 學年度**下學期**（一下）
- 版本：**南一版** 一下數學（9 個單元，單元目錄與來源見 `UNITS.md`）
- 入口：`index.html`（可直接用瀏覽器開啟，離線可玩；滑鼠、觸控都可以操作）
- 進度存在 localStorage，key：`math-g1-2-stars`（不會和上學期 `math-g1-stars` 混在一起）

## 一年級的設計
- 字大（題目 27px 以上、數字 46px），按鈕大、好點。

## 列式小幫手（2026-11）
應用題不用拿紙算：小朋友點題目裡的數字和 ＋ − 列出算式，列對了電腦自動算出答案（`js/core.js` 的 `eqBuild`，題目物件寫 `eq: [a, '+' 或 '−', b]`）。
一年級版：只有一步、只用點的（沒有數字鍵）、符號只有 ＋ −，數字按鈕附小圖示（`icon`），題目、提示、答案都會朗讀；＋ 前後交換也算對，減法放反會提醒「大的數放前面」。

用在：
- 2-B 連加和算式：比較型加法（小兔子比小松鼠多幾顆）
- 3-B 比一比誰長：毛毛蟲比蝸牛長幾個迴紋針
- 3-C 接起來剪下來：接起來、剪掉、部分和全部
- 4-B 減法和比較：拿走、比多幾、部分和全部、比較少
- 8-B 加減應用題：全部 4 種題型
- 9-C 看統計表：多幾人、一共幾人

沒有改：數數／位值／百數表（第 1 單元）、湊十與心算快手（2-A、2-C、4-A、4-C，本來就在練計算）、選算式與「接哪一條」等選擇題、長度實作、圖形（第 5 單元）、月曆（第 6 單元）、錢幣（第 7 單元）、十條和一個與加減關係（8-A、8-C）、分類與數一數（9-A、9-B）。

## 📝 月考測驗卷（2026-11，第 2 版）

- 題庫：`js/exam-bank.js`（`window.EXAM_BANK`，有 grade、papers、bank）。
