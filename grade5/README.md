# 五年級數學樂園（五福國小・南一版 五上）

高雄市鳳山區五福國民小學，115 學年度上學期，五年級數學。版本：**南一**（學校官方教科書單）。
本版取代舊的「五上數學雙維度視覺實驗室」（舊版依康軒版製作，單元不同）。

## 怎麼玩
- 直接用瀏覽器打開 `index.html` 就能玩，不用網路、不用安裝；滑鼠、平板觸控都可以操作。
- 題目由「貓頭鷹老師」朗讀（Web Speech API，zh-TW），🔊 可再聽一次，右上角可關聲音。
- 答案用小鍵盤輸入，分數用「／」、帶分數用「又」，分數要約成最簡分數。
- 每關最多 3 顆星（全對 3、錯 1–2 次 2、更多 1），存在 localStorage key `math-g5-stars`。
- 左上「← 選年級」連到 `../index.html`；全站 `home-button.js` 由總管統一加入。全部相對路徑，可直接複製到 repo 的 `grade5/`。

## 測試紀錄（2026-10-24）
- 所有 js 跑過 `node --check`。
- 用瀏覽器（localhost）打開，30 關都進得去、沒有 console 錯誤；用腳本實際操作每一關（拖曳畫點、塗方格、點符號、選展開圖、小鍵盤輸入）都能過關、拿到星星。
- 每一題隨機產生 400 次自動檢查：選擇題只有一個正解、選項不重複，鍵盤題答案是正整數或最簡分數，而且用鍵盤打得出來並判為正確。算式拆彈的運算順序、正方體展開圖的摺疊判斷（5 種內建展開圖可摺、兩種錯誤排法會被拒絕、相對面）另外用 node 驗證。
