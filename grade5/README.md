# 五年級數學樂園（五福國小・南一版 五上）

高雄市鳳山區五福國民小學，115 學年度上學期，五年級數學。版本：**南一**（學校官方教科書單）。
本版取代舊的「五上數學雙維度視覺實驗室」（舊版依康軒版製作，單元不同）。

## 怎麼玩
- 直接用瀏覽器打開 `index.html` 就能玩，不用網路、不用安裝；滑鼠、平板觸控都可以操作。
- 題目由「貓頭鷹老師」朗讀（Web Speech API，zh-TW），🔊 可再聽一次，右上角可關聲音。
- 答案用小鍵盤輸入，分數用「／」、帶分數用「又」，分數要約成最簡分數。
- **列式小幫手（2026-11）**：應用題不用自己算，只要把算式列對就過關（點題目裡的數字或用鍵盤打，＋−×÷ 選符號，多步題一列算一步，可以點「用前面的答案」），答案由電腦用**精確分數**算（不會有 0.1 + 0.2 的誤差），分數、帶分數、小數都能列。列錯會依「符號／前後順序／題目沒寫的數要換算／空格」給提示。
  - 用在：2-C 倍數個數（顯示商…餘）；3-C 求未知角、內角和、正多邊形每個內角、等腰底角；5-C 周長、對稱點距離；6-C 果汁、緞帶分數應用題；7-C 連除、找錢、平均；8-C 全部 6 題面積；9-C 練琴、影片平分、火車時數、時分 ÷ 整數；10-C 表面積、邊長總和、無蓋紙盒、由邊長總和求邊；🎯 進階挑戰第 3、5、6、7、8、9、10 單元的計算應用題（共 16 題）。
  - 沒有改的：統計圖讀值（1-C、1-D，練讀圖）、因數倍數／公因數公倍數（2-C、2-D，練找因數）、擴分約分通分（4-C、4-D，練觀念）、6-C 前 3 題與 6-D 第 1 題（練分數加減計算本身）、7-C 簡化計算 3 題與 7-D 計算順序題（練計算規則）、3-C 第三邊最長、5-C 對稱觀念題、10-C 由表面積求邊長（要想「誰乘自己」，不是四則）、所有選擇題與動手做關卡。
  - 寫法：`core.js` 的 `eqBuild`，題目物件加 `` eq: `(${t} + ${b}) × ${h} ÷ 2` ``（也接受三年級的 `[a, op, b]` 陣列），`alt` 放其他正確列法，`known` 放題目沒寫但會用到的數（180、60…），`chips` 補題目用國字寫的數。連加減、連乘除裡先算哪兩個數都算對；＋、× 前後交換也算對。
- 每關最多 3 顆星（全對 3、錯 1–2 次 2、更多 1），存在 localStorage key `math-g5-stars`。每單元 4 關（含 🎯 進階挑戰），總星數 120。
- 左上「← 選年級」連到 `../index.html`；全站 `home-button.js` 由總管統一加入。全部相對路徑，可直接複製到 repo 的 `grade5/`。

## 測試紀錄（2026-10-24）
- 所有 js 跑過 `node --check`。
- 用瀏覽器（localhost）打開，30 關都進得去、沒有 console 錯誤；用腳本實際操作每一關（拖曳畫點、塗方格、點符號、選展開圖、小鍵盤輸入）都能過關、拿到星星。

## 📝 月考測驗卷（2026-11，第 2 版）

年級首頁的單元選單下面有一個獨立的「📝 月考測驗卷」區塊（`index.html` 的 `#exam-box`，由全站共用的 `kg-exam.js` 畫出），是給月考複習用的正式試卷，不是遊戲：每張 40～50 題，依「一、是非題　二、選擇題　三、填充題」排列，交卷後計分（80 分 ★、90 分 ★½、100 分 ★★），可對答案、看解說、「只看錯的」，記錄最佳成績。題目每次會換。

- 題庫：`js/exam-bank.js`（`window.EXAM_BANK`，和遊戲關卡的題目分開）。函式題每次亂數出題，一個函式算 5 題。
- 每題都有解說，陷阱題的解說寫出「陷阱」在哪裡。選擇題的錯誤選項用常見錯誤觀念。
- 試卷：期中考範圍（第 1～5 單元，45 題）、期末考範圍（第 6～10 單元，45 題）、全冊總複習（50 題）。期中／期末依 10 個單元對半分。
- 範圍跟遊戲一樣：不出質數、質因數分解（六上）；不出小數乘法、分數乘法、體積、容積（五下）。分數填充寫成 3/4 或 1又5/12（約分、沒約分、假分數都算對）。折線圖用程式畫的 SVG。
- 參考的公開資料（只參考題型、範圍和常見陷阱，題目全部自己重寫，沒有照抄）：
  - 教育雲教學資源平台 南一版五上數學期中評量試卷（CC 授權學習單）：https://market.cloud.edu.tw/resources/web/1623903
