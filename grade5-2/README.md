# 五年級下學期・沙漠金字塔尋寶隊（數學）

- 學校：高雄市鳳山區五福國民小學，115 學年度**下學期**（五下）
- 版本：**南一版** 五下數學（10 個單元，單元目錄與來源見 `UNITS.md`）
- 入口：`index.html`（可直接用瀏覽器開啟，離線可玩；滑鼠、觸控都可以操作）
- 進度存在 localStorage，key：`math-g5-2-stars`（不會和上學期 `math-g5-stars` 混在一起）
- 左上角「← 選年級」連到 `../index.html`；`home-button.js`、`bgm.js` 由總管統一加入
- 每個關卡畫面的標題元素是 `#lvTitle`（class `lv-title`），首頁標題是 `h1.hub-title`

## 檔案
