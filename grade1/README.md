# 一年級數學樂園（五福國小・南一版 一上）

高雄市鳳山區五福國民小學，115 學年度上學期，一年級數學。
版本：**南一**（學校官方教科書單）。

## 怎麼玩
- 直接用瀏覽器打開 `index.html` 就能玩，不用網路、不用安裝。
- 滑鼠和平板觸控都可以操作（拖曳的地方也可以「點一下」代替）。
- 每題都會由「貓頭鷹老師」唸出題目（Web Speech API，中文 zh-TW 語音）；按對話框右上角 🔊 可以再聽一次，右上角按鈕可以關掉聲音。
- 每關最多 3 顆星：全對 3 顆、錯 1–2 次 2 顆、錯更多 1 顆。星星存在瀏覽器的 localStorage（key：`math-g1-stars`），首頁可以清除。
- 所有關卡都開放，不用照順序解鎖。
- 左上角「← 選年級」連到 `../index.html`（數學科年級選單，由總管整合）。
- 所有檔案都用相對路徑，整個資料夾可直接複製到 repo 的 `grade1/`。

## 單元與關卡對照表
| 單元（南一 一上） | 🖐 動手做 | 💡 想一想 | 🏆 挑戰 |
|---|---|---|---|
| 1 數到 10 | 點點數數：一個一個點，數完選數字 | 數字配對：數字↔數量，認識 0 | 拿出幾個：拖進籃子剛好 N 個（含拿 0 個） |
| 2 比長短 | 對齊比一比：把鉛筆拖到起點，再點比較長／短的 | 數格子：用一樣大的格子量長度，比長短、一樣長 | 排排看：從最長點到最短 |
| 3 分與合 | 分糖果：點糖果換盤子，分成兩份，說出「N 可以分成 a 和 b」 | 合起來：兩堆合起來幾個；藏起來幾個（分合圖） | 分合圖挑戰：數字鍵盤填分合圖 |
| 4 順序和多少 | 幾個和第幾個：圈出「3 個」和「第 3 個」 | 比多少：一個對一個，哪個多、多幾個、一樣多 | 順序挑戰：數的前後、多 1 少 1、比大小、從前／後數第幾個 |
| 5 數到 30 | 十個一數：把東西放進十格框，幾個十和幾個一 | 十和一：一捆 10 枝吸管說數字；數字拆成十和一 | 數字排排站：順數倒數填空、比大小 |
| 6 加一加 | 放進籃子：添加型加法，寫出 a + b = ? | 看圖選算式：添加型、合併型情境 | 加法快手：10 以內加法、a + □ = c |
| 7 認識形狀 | 形狀分類：圓形、三角形、正方形、長方形拖進框框 | 找形狀：轉向、大小不同仍是同一形狀；邊沒有圍起來不是三角形 | 數形狀：房子、火箭、機器人圖裡數形狀（可點選做記號） |
| 8 減一減與加減應用 | 飛走了：點氣球飛走（拿走型），寫出 a − b = ? | 加還是減：讀題選算式（拿走、添加、合併、比多少） | 加減快手：10 以內減法、加法、a − □ = c |
| 9 讀鐘錶 | 撥撥時鐘：拖動長針、短針撥到整點／半點 | 看鐘說時間：整點、半點 | 生活時間：起床、午餐、放學選時鐘；哪個比較早；過 1 小時 |
