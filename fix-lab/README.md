# 數學故障修復局：重啟任務！

把孩子常犯的數學錯誤，變成一台台「故障機器」。孩子先在示範題裡**找出機器錯在哪一步**，再**連續答對 5 題相似題**，機器就會「修好重啟」（有動畫）。

- 頁面：`publish/math5a-lab/fix-lab/index.html`（上線後是 `https://kuog88.github.io/math5a-lab/fix-lab/`）
- 不屬於任何單元，是數學科的獨立頁面；入口建議放在數學首頁、各年級頁上方、錯題本（由總管加）。
- 點子來自別人分享的同名複習遊戲，這裡只取「把錯誤做成修復任務」的點子；機器、題目、畫面都是原創。
- 畫面不出現校名。

## 怎麼玩

1. **送修（機器從哪裡來）**，三種方式：
   - 🔍 **自動掃描錯題**：讀這台裝置 `localStorage` 的 `kg-report-v1`（家長報表），把數學各年級遊戲和月考測驗卷的錯題逐題判斷，列出可能的錯誤類型、題數、例題，家長勾選後送進工廠。判斷不出來的歸到「其他」並列出例題給家長看。
   - ☑️ **家長勾選**：選年級，依孩子作業、習作上常錯的地方勾選類型。
   - ✍️ **輸入一題錯題**：輸入題目、孩子的答案、正確答案（不做拍照辨識），系統建議可能的類型讓家長確認，也可以自己從清單選一類。
   - 也可以從「看 N 年級全部機器」直接挑一台來修。
2. **修理任務**（每台機器）：
   - **示範**：機器人用錯誤的方法算一題，孩子點出「錯的那一步」。點對後顯示「錯在哪裡」「正確觀念」和這一題的正確做法。若同樣的錯誤出現在好幾步（例如連續兩位都忘了進位），點任何一步都算對，全部標紅。
   - **練習**：5 題相似題（數字亂數）。答錯會顯示正確答案和原因。
   - **5 題全對 → 修好重啟**（進度條、齒輪、火花動畫）；沒全對可以「再校正一次」或「再看一次示範」。
   - 已修好的機器可以再練；之後自動掃描又偵測到同一類錯，機器會再變回故障。
3. **列式類**（看到「多」就加、兩步驟只算一步、乘除用錯、基準量看反）沿用列式小幫手的做法：把算式列對就好，答案由電腦算（支援兩步驟與小數，＋ × 前後交換也算對，兩步驟可換順序）。

### 網址參數（給入口用）

- `?grade=3`：先選好年級（年級頁的入口可帶自己的年級）
- `?go=scan`：直接打開「自動掃描錯題」（錯題本的入口建議用這個）
- `?go=entry`：直接打開「輸入一題錯題」；`?go=pick`：直接打開「家長勾選」

## 存檔與報表

- 進度存在 `localStorage` 的 **`kg-fixlab-v1`**：`{ grade, machines: { 類型id: { g, src, added, fixed, wins, tries } }, entries: [家長輸入的錯題], muted }`。全站換孩子時會自動分開，不用另外處理。
- **家長報表**：每台機器是一個關卡，名稱「故障修復：類型名稱」，單元寫「N 年級 單元」。示範的「找錯的步驟」和每一題練習都記錄（題目、孩子的答案、正確答案）；一輪結束記 `done`（5/5 三星、4 題二星、3 題一星）。報表程式是非同步載入的，還沒載好時會先記住關卡，第一次作答時補上。
- 自動掃描**不讀**故障修復局自己的紀錄（`math5a-lab/fix-lab`），只讀其他數學遊戲（`math5a-lab/…` 或科目為「數學」），包含月考測驗卷。
- 音效是遊戲內的短嗶聲，右上角 🔊 可關；本頁沒有加背景音樂（`bgm.js` 由總管的 `publish.sh` 決定要不要加）。

每個年級可用的類型數：1 年級 9、2 年級 14、3 年級 20、4 年級 21、5 年級 20、6 年級 17（一類可跨年級，依「最早適用的年級」分組）。單元名稱依 `curriculum/math.json` 的南一版 115 學年度。作答方式：數字鍵盤、分數（可輸入 `/` 和「又」）、多格（商/餘、時/分）、選擇、列式。

## 自動判斷規則（`diagnose.js`）

輸入一題錯題的「題目、孩子的答案、正確答案」（報表裡的 `q / a / c`），依序檢查，可能同時符合好幾類：

**① 重算法（最可信）**：從題目抓出算式（例如 `4728 + 1385`、`20 + 4 × 5`、`2/7 + 3/7`），用「錯誤的做法」再算一次，剛好等於孩子的答案就判定：

| 題目算式 | 孩子的答案等於… | 判定 |
|---|---|---|
| 整數 ＋ | 每一位相加但不進位 | 進位沒加 `carry` |
| 整數 ＋ | 位數少的那個數靠左對齊後相加 | 直式數位沒對齊 `align` |
| 整數 ＋（20 以內） | 正確答案 − 1 | 往後數把起點算進去 `count-on` |
| 整數 − | 每一位都用大減小 | 不夠減就倒過來減 `big-small` |
| 整數 − | 借位後前一位沒減 1 | 借位後忘記減 1 `borrow-forget` |
| 整數 −（被減數十位是 0） | 正確答案 + 10 | 中間有 0 的連續退位 `borrow-zero` |
| 整數 ×（一位數） | 每一位相乘但不進位 | 乘法進位沒加 `mul-carry` |
| 整數 ×（二位數） | 第二行沒左移（被乘數 × 兩個數字的和） | 第二行沒往左移 `mul-shift` |
| × 0、× 10 | 不是 0／算成 ＋ 10 | 乘 0、乘 10 算錯 `mult-zero` |
| 整數 ÷ | 正確的商拿掉 0 | 商中間漏寫 0 `div-zero-quot` |
| 小數 ＋ − | 最後一位對齊算出的結果 | 小數點沒對齊 `decimal-align` |
| 分數 ＋ | 分子加分子、分母加分母 | 同分母 `same-den-add`／異分母 `unlike-frac` |
| 分數 × 整數 | 和原來的分數一樣大 | 分母也乘 `frac-times-int` |
| 帶分數 × 整數 | 只乘了整數部分 | `mixed-times-int` |
| 分數 ÷ 分數 | 正確答案的倒數 | 顛倒錯邊 `frac-div` |
| 小數 ÷ 小數 | 正確答案的 1/10 | 只移除數的小數點 `dec-div` |
| 小數 ÷ 整數 | 差 10 的次方倍 | 商的小數點沒對齊 `dec-div-int` |
| 小數 × | 差 10 的次方倍 | 小數點位數點錯 `dec-mult`／`dec-times-int` |
| 三個數（加減和乘除混合） | 從左往右算的結果 | 沒先乘除後加減 `order-ops` |
| 三個數（同一級） | 先算後面的結果 | 沒由左往右 `left-right` |

**② 答案關係 + 題目關鍵字**：

| 條件 | 判定 |
|---|---|
| 答案有「商…餘」，餘數 ≥ 除數 | 餘數比除數大 `div-remainder` |
| 時/分答案的分鐘 ≥ 60，或和正確答案差 40 分；或把「分鐘」用 100 換成時 | 時間 60 進位當 100（依年級：經過時間 `elapsed-60`、時間相減 `time-borrow`、時間乘除 `time-multiply`） |
| 「經過」題差 40 分鐘 | `elapsed-60` |
| 半點時答成下一個小時 | `clock-half`；長針數字直接當分鐘 → `clock-minute` |
| 題目有「約分/最簡」，大小對但還能約 | `reduce` |
| `a/b = □/c`，答案是用加的 | `equiv-frac` |
| 「n 顆 … k/d 盒」只算了一份 | `frac-of-whole` |
| 題目有「比…多/少」，孩子用了相反的加減 | `keyword` |
| 題目有「倍」，該除卻乘（或相反） | `base-amount` |
| 「幾個幾」答成相加 | `mult-add`；「每箱/平分」該除卻乘 → `mul-div-choice` |
| 面積和周長互換 | `area-perimeter`；三角形/梯形答案是 2 倍 → `triangle-half`；平行四邊形用斜邊 → `slant-height` |
| 圓面積差 4 倍或用了周長公式 | `circle-area`；圓柱 → `cylinder`；半徑直徑差 2 倍 → `radius-diameter` |
| 角度題兩個答案加起來 180 | `protractor` |
| 最長/最多 ↔ 至少/同時，GCD 和 LCM 互換 | `gcd-lcm`；因數倍數題 → `factor-multiple` |
| 比值是倒數 | `ratio-order`；「折」題算成便宜的錢 → `discount` |
| %、比例尺、速率題差 10 倍／100 倍／60 倍 | `percent`、`scale`、`speed-unit` |
| 單位題：答案是兩個數直接接起來，或差 10 的次方倍 | 公尺公分 `m-cm`、公分毫米 `mm-cm`、公升/公斤/公里 `thousand-unit`、平方/立方/公頃 `big-unit` |
| 十位個位對調、大數漏 0、四捨五入、單位分數、小數比大小、第幾個差 1、尺沒從 0 量、只數錢幣個數 | 各自的類型 |
| 題目有 3 個以上數字、答案剛好是前兩個數算一步 | 兩步驟只算一步 `two-step` |

**③ 大方向**（前面都沒中才用）：

- 答案和正確答案**差 10 倍、100 倍**：題目有小數 → 小數點位置（依年級選小數類型）；題目有單位 → 單位換算；都沒有 → 位數對齊。
- 答案**差 10、100、1000**：加法 → 進位沒加；減法 → 借位忘記減 1；乘法 → 乘法進位。
- 都不符合 → **「其他」**。

年級：從報表的遊戲 id 讀（`math5a-lab/grade3-2` → 3 年級），機器會用最接近的適用年級出題。

## 測試結果（2026-11-04）

- `node tests/verify.test.js`：65 類 × 每個適用年級 × 300 次 = **30,310 題，全部通過**。檢查：答案和獨立解法一致、錯誤答案一定和正確答案不同、作答判斷接受正確答案且拒絕錯誤答案、選擇題選項不重複且包含正確答案與錯誤答案、列式（含另一種列法）算出來等於答案而且只用到題目裡的數字、中間結果不是負數或除不盡、示範步驟和「錯的那一步」有效、文字沒有 undefined/NaN、沒有校名。
- `node tests/diagnose.test.js`：用每一類自己的錯誤答案測，**65/65 類**在 100 題中認出 ≥ 90 題；假的 `kg-report-v1`（6 個年級 17 題，含 1 題無法判斷、1 筆故障修復局自己的紀錄、1 筆社會科）**全部判對**，自己的紀錄和社會科都沒有被讀進來。
- 隨便亂錯（答案 + 7）的誤判：2850 題中 189 題被歸到某一類，大多是題目本身就屬於該類（例如四捨五入題、圓柱題、× 0 題），其他歸「其他」。
- 瀏覽器（關掉背景音樂和音效，375 寬手機畫面）：用假的報表自動掃描 → 正確列出 7 類＋1 題其他 → 送進工廠；實際點擊修好「進位沒加」「借位後忘記減 1」「餘數比除數大」「分數相加，分母也相加」（含一輪 4/5 重來），以及家長勾選的「該用除法卻用乘法」；再用程式在畫面上把 **65 台機器各修 2 輪（650 題）**，正確答案全部被接受、畫面沒有左右超出；家長報表的關卡名稱、單元、題目、孩子的答案、正確答案都正確。
