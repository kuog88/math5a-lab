# 四年級數學樂園（五福國小・南一版 四上）

高雄市鳳山區五福國民小學，115 學年度上學期，四年級數學。
版本：**南一**（學校官方教科書單）。

## 怎麼玩
- 直接用瀏覽器打開 `index.html` 就能玩，不用網路、不用安裝；滑鼠和平板觸控都可以操作。
- 題目由「貓頭鷹老師」朗讀（Web Speech API，zh-TW），右上角可關聲音。
- 多位數答案用數字小鍵盤輸入（最多 9 位；小數題會多一個「.」鍵）。
- 每關最多 3 顆星：全對 3 顆、錯 1–2 次 2 顆、錯更多 1 顆。存在 localStorage（key：`math-g4-stars`），首頁可以清除。
- 左上角「← 選年級」連到 `../index.html`。全站「回遊戲樂園」按鈕（`home-button.js`）由總管統一加入。
- 全部使用相對路徑，整個資料夾可直接複製到 repo 的 `grade4/`。
